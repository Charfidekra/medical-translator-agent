# AI Agent لترجمة الكتب الطبية (فرنسي ⇾ إنجليزي)

مشروع Multi-Agent مبني بـ **Python + CrewAI** يترجم النصوص الطبية من الفرنسية
إلى الإنجليزية عبر 3 وكلاء متسلسلين:

```
[نص فرنسي] ⇾ [Agent 1: Translator] ⇾ [Agent 2: Terminology Checker] ⇾ [Agent 3: Clinical Proofreader] ⇾ [نص إنجليزي نهائي]
```

## 1. التثبيت

```bash
cd medical_translator_agent
python -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. إعداد مفتاح الـ API

أنشئي ملف `.env` في نفس المجلد وحطي فيه:

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx
```

(تقدري تجيبي المفتاح من console.anthropic.com — لا تشاركيه مع حتى حد)

## 3. الاستعمال

### 🎨 الطريقة السهلة: واجهة Streamlit

```bash
streamlit run app.py
```

هاد الأمر يفتح واجهة فالمتصفح فيها:
- **رفع ملف** (.txt أو .pdf) أو **لصق نص مباشر**
- **شريط جانبي**: إدخال مفتاح الـ API، ضبط حجم القطعة (Chunk Size)، وزر لبناء/تحديث قاعدة بيانات المصطلحات
- **شريط تقدم** يتابع ترجمة كل قطعة
- **عرض متوازي** لكل قطعة: العمود الأيسر فيه النص الفرنسي الأصلي + المصطلحات المسترجعة من المعجم (RAG)، والعمود الأيمن فيه الترجمة الإنجليزية النهائية
- **زر تحميل** للترجمة الكاملة كملف .txt
- **مراجعة وتصحيح بشري**: كل ترجمة قابلة للتعديل مباشرة، مع زر "حفظ التصحيح" وإمكانية إضافة مصطلح جديد للمعجم فورياً
- **سجل مراجعات كامل**: صفحة منفصلة تعرض كل التصحيحات المحفوظة تاريخياً

⚠️ أول مرة، لازم تضغطي "بناء / تحديث قاعدة البيانات من المعجم" فالشريط الجانبي قبل ما تبدئي الترجمة.

### 💻 الطريقة اليدوية: سطر الأوامر (Command Line)

#### أ) ترجمة نص مباشر (اختبار سريع)
```bash
python main.py
```
(بلا أي argument، يستعمل نص تجريبي جاهز باش تتأكدي بلي كلشي خدام)

#### ب) ترجمة نص من ملف txt
```bash
python main.py --file mon_chapitre.txt --output chapitre1_en.txt
```

#### ج) ترجمة فصل من كتاب PDF
```bash
# الخطوة 1: استخراج النص من الصفحات 10 لـ 25
python extract_pdf.py --pdf anatomie.pdf --start 10 --end 25 --output chapitre1.txt

# الخطوة 2: ترجمته
python main.py --file chapitre1.txt --output chapitre1_en.txt
```

## 4. هيكل المشروع

| الملف | الدور |
|---|---|
| `config.py` | إعدادات عامة (مفتاح API، اسم النموذج، حجم القطعة، مسارات قاعدة البيانات) |
| `prompts.py` | الـ System Prompts لكل وكيل من الثلاثة |
| `agents.py` | تعريف الوكلاء الثلاثة بـ CrewAI |
| `tasks.py` | ربط الوكلاء في سلسلة مهام (Translate → Check → Proofread) |
| `main.py` | نقطة الدخول لسطر الأوامر: تقسيم النص، استرجاع المصطلحات، تشغيل الـ Crew |
| `extract_pdf.py` | استخراج النص من كتب PDF |
| `terminology_db.py` | بناء واستعلام قاعدة بيانات المصطلحات (RAG) بـ ChromaDB |
| `data/medical_terms_seed.csv` | معجم بذرة بمصطلحات طبية شائعة (فرنسي-إنجليزي) |
| `app.py` | واجهة Streamlit التفاعلية (رفع ملف، عرض متوازي، تحميل النتائج، مراجعة بشرية) |
| `review_history.py` | تخزين واسترجاع سجل التصحيحات البشرية (SQLite) |

## 5. قاعدة بيانات المصطلحات (RAG) — كيفاش تخدم

قبل بناء قاعدة البيانات لأول مرة (من سطر الأوامر)، لازم تشغلي:

```bash
python terminology_db.py
```

أو غير اضغطي زر "بناء / تحديث قاعدة البيانات من المعجم" فالشريط الجانبي فواجهة Streamlit.

هاد الأمر:
1. يقرأ المعجم من `data/medical_terms_seed.csv`.
2. يحمّل نموذج embedding صغير (~90MB) أول مرة فقط (يحتاج اتصال إنترنت عادي).
3. يبني قاعدة البيانات فـ `data/terminology_db/`.

بعد هذا، كل ترجمة (من سطر الأوامر أو من الواجهة) راح تبحث تلقائياً على
المصطلحات ذات الصلة فكل قطعة نص، وتعطيها للـ Translator Agent كسياق موثوق.

**باش تزيدي مصطلحات جداد للمعجم:**
- زيدي سطر فـ `data/medical_terms_seed.csv` (نفس الأعمدة: french_term, english_term, domain, notes)
- عاودي شغلي `python terminology_db.py` (يستعمل `upsert` فما يكررش المصطلحات الموجودة)

**ملاحظة:** إذا واجهتي خطأ `SHA256 hash mismatch` عند أول تشغيل، هذا يعني
مشكلة مؤقتة فتحميل النموذج (شبكة بطيئة/متقطعة) — امسحي مجلد الكاش
(`~/.cache/chroma`) وعاودي المحاولة.

## 6. نظام المراجعة البشرية (Human Review History)

بعد كل ترجمة، تقدري:

1. **تعدلي الترجمة مباشرة** فمربع النص القابل للتعديل (العمود الأيمن).
2. **تضيفي مصطلح جديد للمعجم** (اختياري) عبر القسم "➕ إضافة مصطلح جديد للمعجم" — دخلي المصطلح بالفرنسية ومقابله بالإنجليزية.
3. **تضغطي "💾 حفظ التصحيح"** — هذا:
   - يسجل النص الأصلي، ترجمة الـ AI، والترجمة النهائية بعد المراجعة، فقاعدة بيانات `data/corrections_history.db` (SQLite)
   - إذا دخلتي مصطلح جديد، يتزاد فورياً لقاعدة بيانات ChromaDB **و** لملف `data/medical_terms_seed.csv` (باش يبقى محفوظ نهائياً)
   - المصطلح الجديد يستعمل مباشرة فالترجمات الجاية بلا ما تحتاجي تعاودي تبني القاعدة كاملة

**لمراجعة السجل الكامل**: اختاري "📋 سجل المراجعات الكامل" من الشريط الجانبي. تقدري تفلتري باش تشوفي غير التصحيحات الفعلية (اللي بدلت فيهم فعلاً) وتستبعدي التأكيدات بلا تعديل.

**الإحصائيات** (مجموع المراجعات، عدد التصحيحات الفعلية، عدد المصطلحات الجديدة) تظهر مباشرة فالشريط الجانبي.

## ملاحظة مهمة

هذا الـ MVP يعتمد على معرفة النموذج بالمصطلحات الطبية القياسية (MeSH/UMLS) من
تدريبه، بدون قاعدة بيانات خارجية بعد. للاستعمال الأكاديمي/السريري الجدي، لازم
مراجعة بشرية (منك أو من مختص) قبل اعتماد أي ترجمة نهائياً — خاصة الأجزاء
المعلّمة بـ `[UNCERTAIN: ...]` أو `[REVIEW NEEDED: ...]`.
